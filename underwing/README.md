# 鹤伴 Underwing（演示版 v0.4，2026-11-17）
电脑优先，手机自动单栏 + 底部导航。
- 开发：改 src/index.html（样式、图标）和 src/app.js（逻辑）→ `python3 build.py` 生成单文件 index.html（插画内嵌）
- 测试：`python3 test_e2e.py`（Playwright，桌面 1440 + 手机 390，34 项）
- 我的卡组：选「我在照顾的情况」→ 推荐卡；卡可加入/移出
- 找照护卡：48 个常见病种（8 组，含别名）+ 搜索 + 自定义病名
- 卡片：在家量血压（临床，4 个来源）；复诊准备、用药记录、症状日记（整理工具，不含临床建议）；测血糖、吸入剂、称体重、防跌倒、伤口观察（编写中）
- 病历夹：时间线、上传图片/PDF（本机 IndexedDB）、AI 整理（自动脱敏→披露→整理→待核对）、复诊准备进度、血压趋势
- AI：默认本地规则整理不联网；设置里可填自有后端代理地址（POST {task,text}，返回 {items:[{kind,date,title,detail}]}），网页不存密钥
