# 居家照护卡片应用：疾病清单全球扩展调研报告 v2（GBD 全筛 + 覆盖率复核）

**调研日期：** 2026年11月17日　**阅读方式：** 本报告所有来源均为网络检索（index）所得，未做逐页 live 核验；凡写“未见可靠数据”处，均指本轮检索未找到可引用的全球代表性数字，不是断言该数字不存在。**本报告与 v1 的关系：** v1（`report.md`，74 张卡）全文结论全部继承，v1 文件未改动。本报告只做两件 v1 留下的事：① 对 GBD 全部病因做逐项筛查，把“本轮未筛查”清零（除明确标注的非 GBD 候选与计数残差外）；② 复核覆盖率计算，说明总覆盖率为何仍然算不出，并给出精修后的前 25 位区间。**产品边界、16 条禁做清单、地区分发规则、急救电话三件套，全部继承 v1 第五至七节，一字不改，本报告不重复。**

**结论先说（给产品决策）：**

1. **全筛完成：** 以 GBD 2017 公开层级名册（168 个三级病因）为底 + 2019/2021/2023 三轮 documented 增减链为补丁，逐项判定全部 GBD 病因的居家照护适用性。结果：**新增 25 张候选卡（Tier 2 20 张 + Tier 3 5 张），清单从 74 张扩至 99 张（待用户确认与专家复核后方可称定稿）**。全部 GBD 病因均有处置（收录/并入/排除/残余类），不再有“本轮未筛查”的 GBD 病因；4 个非 GBD 候选（慢性静脉功能不全、眩晕、失眠、ME/CFS）明确标为“未筛查/证据不足”，不冒充已判定。
2. **总覆盖率仍然算不出。** 任务二的数据获取路径已穷尽：GHDx 附录 3 全表、GBD Results Tool、GBD Compare 均须 IHME 账号登录（免费账号，未建——建号须用户邮箱与验证，本任务未授权）；公开渠道无镜像。唯一诚实解封路径：用户或专家以 IHME 账号下载附录 3 表 1–13（表 S3）交 agent 提取。在此之前，产品内仍不得宣称任何总覆盖百分比。
3. **前 25 位区间精修为 43.0%–50.9%。** 新增依据：GBD 2023 论文表 1 给出跌倒 YLD 53.1 百万，可算出跌倒致死部分 21.2 百万（28.5%）；严格下限按“跌倒仅计非致死部分”精修为 43.0%（v1 口径严格下限 43.8% 仍保留作对照，两数算法不同，不得混用）。区间仍为点估计口径，UI 未纳入。
4. **四处边界须专家先裁决、再建卡：** ① 运动神经元病（罕见病规则第 12/17 条的解释——居家照护中心性 vs 罕见病排除）；② 唐氏综合征（遗传病规则的解释，与已收录的镰状细胞病/地中海贫血先例对照）；③ 疥疮（WHO 认定 NTD，但 GBD 归皮肤病组——按 GBD 分组收录，须专家确认）；④ 良性/原位肿瘤（B.1.30）是否并入“恶性肿瘤通用卡”、卡名是否改为“肿瘤居家通用卡”。四处裁决未过，相关卡不建。
5. **“99%”结论不变：** 按病种数算永远不可宣称（见 v1 1.1）；按 DALY 算，总覆盖率算不出（见本报告第八节）。产品表述模板见本报告第十一节（99 张版草案，待确认后方可启用；确认前沿用 v1 的 74 张版）。

## 一、筛查方法与名册（任务一的方法论，可审计）

### 1.1 名册来源与局限（必须先读）

1. **GBD 2023 官方层级文件取不到。** GHDx 记录 `IHME_GBD_2023_HIERARCHIES_Y2025M10D23.XLSX` 与附录 3 全表一样，须 IHME 账号登录（见第八节）。本轮未绕过登录墙。
2. **替代名册：GBD 2017 公开层级（最新完整公开版）。** 来源：IHME《GBD 2017 Tools Overview》（2018 年 11 月，78 页 PDF，第 4.2 节层级表），经 `pdftotext -layout` + 解析脚本提取，**359 个节点（1 总计 + 3 个一级 + 22 个二级 + 168 个三级 + 165 个四级），最细层级 293 个，0 解析失败**。核对：GBD 2017 公布的“359 种疾病与伤害”即全部层级节点数，与提取结果一致。
3. **增减链（2019→2021→2023，全部取自各轮 capstone 论文正文/附录，见 1.2）。** 名册 = 2017 底表 + 增减链。**残差声明：** 2019 年三级病因计数存在 ±1 残差（168+5=173 vs 公布 174），无法裁决其来源（可能为计数口径），本报告不强行调平；该残差不影响任何一张卡的判定（全部具名病因均已逐项列出），只影响“总数”表述——本报告不宣称“已筛查全部 375 项中的每一项三级病因”这一精确计数，只宣称“全部具名病因均有处置”。
4. **筛查单位：** 三级病因 + 处置不同的四级拆分（如皮炎三亚型、视力损害五亚型、先天异常各亚型、泌尿/妇科/血红蛋白病各亚型）。v1 已有先例：T2-18/19（BPH、尿石症）、T2-26/39/40（肌瘤、内异症、PCOS）、T2-30（特应性皮炎）、T3-4（先心病）均为四级病因卡——v2 沿用同一做法，不新增规则。
5. **判定标准（与 v1 1.3 完全一致）：** 已确诊后存在 3–6 项可由无护理经验家属执行的居家任务（操作、观察、记录、复诊提醒），且不触碰 16 条禁做清单；窄范围高风险者入 Tier 3；残余类（“其他××”）不单独立卡；急性期/院内主导/专科主导/严重精神障碍与成瘾/罕见遗传病按 v1 第六节逻辑排除（四处边界解释见结论第 4 条）。

**跌倒拆分（本轮新算，可复算）：** 跌倒 DALY 74.3 百万 − YLD 53.1 百万 = YLL 21.2 百万（致死部分占 28.5%）。此拆分精修了 v1 敏感性说明第 2 条（v1 称拆分未取得）。

**精修算术（单版本 GBD 2023，点估计口径，UI 未纳入）：**

- v1 严格口径下限：1,225.0 百万 ÷ 2,800 百万 = **43.8%**（跌倒全额计入，含致死部分）。
- 精修严格口径下限：(1,225.0 − 21.2) 百万 ÷ 2,800 百万 = 1,203.8 ÷ 2,800 = **43.0%**（跌倒仅计非致死 YLD 部分，卡片只覆盖预防与伤后居家段）。
- 上限不变：**50.9%**（宽松口径，三个部分口径病因与残余类全额计入，含 v1 敏感性说明第 1 条的乐观假设）。
- **精修区间：43.0%–50.9%。** 引用时须同时注明：点估计口径、UI 未纳入、上限含乐观假设、下限算法（跌倒 YLD-only）与 v1 的 43.8% 不同。

**不做的计算（纪律声明）：** ① 不用表 1 的 YLD 数另算一个“YLD 覆盖率”——会制造第二个易混淆的 headline 数字；YLD 表仅作跌倒拆分的依据与背景。② 不把新增 25 张卡的 GBD 2021/WHO 数字与 GBD 2023 总量相加。③ 不用患病数推算 DALY。④ 不用率反推总数。

### 8.4 v1 §1.2 公式结果：仍然算不出

覆盖率 = 已收录卡片对应病因 DALY 之和 ÷ 清单 B DALY 总和 × 100%。本轮完成了清单 B 的**成员判定**（第六节处置表），但仍缺两件：① 表 S3 的 26–375 位逐项 DALY 明细（见 8.1）；② 专家对处置表的逐项复核（处置表为调研判定，不是临床定稿）。两件缺一，公式结果即算不出。**解封路径（唯一诚实路径）：** 用户或专家以免费 IHME 账号下载附录 3 表 1–13（表 S3）交 agent 提取 + 专家逐项复核处置表 + 残余类/综合征/部分口径病因的映射规则与计入比例书面依据 → 复算并公开计算表。在此之前，产品内不得宣称任何总覆盖百分比（v1 1.6 的无百分比表述继续适用）。
