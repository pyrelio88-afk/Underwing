# 作品：鹤伴 Underwing — 居家照护卡 + 病历夹
> 2026-11-17 更正：这是用户参加**另一个黑客松**的项目，不是 Qoder 大赛作品；由 Hark 直接开发。具体是哪个黑客松、截止时间未知。
用户 2026-11-17 给出的计划要点：
1. 目标：无护理经验的患者/家属快速找到讲得清的居家照护卡；需要时按时间整理个人记录。不诊断、不代替医生、不建议停药改量。
2. 验证：5–8 位患者/家属短访谈（卡点、用过的资料、最难理解的一步），只用于发现问题。
3. 首个切片候选：家庭血压测量卡+虚构读数时间线 vs 出院后复诊准备清单，按访谈选一个做完整流程。
4. 卡片模板：一卡一事；适用情境、步骤图、易错点、何时停下联系医护、来源与更新时间；临床信息可溯源；不写成通用硬指令。
5. 病历夹：按人整理就诊/检查/用药时间线，日期、原始来源、"待核对"；首版只用标注虚构资料；AI 只出可对照草稿，用户确认后保存。
6. 隐私：不放真实病历；不在浏览器暴露 API Key；不承诺匿名；接云端 AI 前先展示发送内容、可编辑/取消、说明存储删除。
7. UI：Gemini 4 高思考重设计 → 研究 iOS 系统界面 + GitHub 组件 → Qwen4 Max 优化代码；大字、留白、层级、可触控，避免 AI 模板感。
8. 50 轮迭代：信息架构/可读性无障碍/视觉系统/卡片交互/真实任务测试 各 10 轮；每轮记录问题、改动、测试、截图/diff；未改未测不计。当前确认完成：0。
9. 验收：目标用户独立找卡、复述关键提醒、完成模拟记录、指出何时求助；记录理解错误、卡点、用时；满意度不抵消危险误解。
