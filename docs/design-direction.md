# UI 设计方向（2026-11-17 用户指定）
参考：https://github.com/pyrelio88-afk/Crane （用户写作 CraneUI；用户自己的仓库，web/index.html 为 Claude 风格 UI）
用户要求：可以适当参考，但**不要黑白，尽量彩色**。

## 从 Crane 借什么
- 纸感暖底 + 细分隔线 + 衬线标题/无衬线正文的层级
- 圆角 8–14px 的卡片，留白多
- 审批卡 → 病历夹里"AI 草稿 → 用户确认后保存"的确认卡
- 置顶待办 → 照护卡里的步骤进度
- 事件日志时间线 → 病历夹的就诊/检查/用药时间线（每条带来源 + 待核对状态）
Crane 原色板（偏墨色单色）：paper #F7F2E7, card #FFFDF8, ink #1B1A17, line #E2DACA, red #C8361F, ok #3E7C4F

## 改成彩色的原则（草案，待用户确认）
- 底色保留暖白，但每类照护卡有自己的主题色（例：血压=珊瑚、复诊准备=青绿、用药=琥珀、伤口护理=蓝紫），用于卡头色条、图标、步骤编号
- 红色只留给"何时停下并联系医护人员"，不作装饰色，避免稀释警示
- "待核对"用醒目但非警报色（如琥珀描边）；已确认用绿色
- 所有文字/背景组合过 WCAG AA（正文 ≥4.5:1），大字号、触控目标 ≥44px
- 不用大面积渐变卡片堆砌（与计划第 7 条一致）


## 2026-11-17 借鉴 Crane 设计稿（用户提供 5 张截图）
- 采用：线稿鹤插画卡 + 右上状态胶囊；侧栏头像 + 副标题列表；按钮层级（主要深色、次要描边、幽灵、每屏最多一个强调）；分段选择器；审批卡 → 核对卡；深色 toast + 撤销；整机体检（环 + 状态行 + 操作按钮）→ 复诊准备；两档线性图标
- 改动：Crane 黑白 + 朱红强调 → 鹤伴暖白 + 分类色；强调按钮用分类色而非红；红色只留给「停下联系医护」；删除按钮不用红
