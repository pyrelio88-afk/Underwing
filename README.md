# 鹤伴 Underwing · 居家照护卡与个人病历夹（轻量化静态版）

鹤伴（Underwing）是一个面向没有医学与护理背景的家属设计的纯静态、本地优先（Local-First）居家照护 Web 应用：一张卡片讲清一件事（为什么做、具体步骤、易错点、何时停下来联系医护、权威出处），配套提供疾病照护图谱扇形展开、床旁大字语音伴读、突发状况红线速查，以及只保存在本机浏览器里的多体征病历夹与一页复诊单。

> 医疗边界说明：鹤伴仅提供健康教育与个人记录整理工具，不诊断疾病、不解读化验指标、不替代执业医护判断，也不建议擅自停药或调整剂量。应用内置的演示人物、病历与读数均为虚构。

## 1. 快速打开与部署方式

本项目零后端、零构建期第三方前端框架依赖，根目录已包含唯一标准构建产物（`index.html` + `assets/`），支持三种方式直接打开或部署：

### 方式一：本地离线直开（`file://`）
直接双击项目根目录的 `index.html` 即可在桌面或移动浏览器中运行。全部脚本采用经典 `<script src="assets/app.js"></script>` 与相对路径加载，不依赖服务端路由重写。

### 方式二：本地 HTTP 静态预览
```bash
python -m http.server 8765 --bind 127.0.0.1 --directory .
# 浏览器打开 http://127.0.0.1:8765/index.html
```

### 方式三：部署至 Qoder Sites / 任意静态托管服务
直接将项目根目录下的 `index.html` 与 `assets/` 目录发布为静态站点（在 Qoder 中可通过会话指令发布至 **Qoder Sites** 或在 `/sites` 面板设为 **Public** 公开访问，部署包共 118 个文件、**3.23 MiB**）。路由基于 URL Hash（如 `#/cards`、`#/library?tab=hubs&hub=04_diabetes`、`#/card/insulin_pen`、`#/folder?chart=glucose`），刷新深链不会触发静态站点 404。

## 2. 核心功能概览

1. **15 张就绪集换式居家照护卡（12 张临床卡 + 3 张通用整理卡）**
   - **临床测量 / 给药 / 安全 / 护理卡（12 张，全部 `◆◆◆ 来源全部核对`）**：`在家量血压`、`在家测血糖`、`吸入剂怎么用`、`每天称体重`、`居家防跌倒`、`居家伤口观察`、`识别低血糖`、`缩唇和腹式呼吸`、`认知障碍日常照护`、`床到轮椅转移`、`胰岛素笔怎么用`、`眼药水怎么滴`。
   - **通用整理工具卡（3 张，`◆ 整理工具 · 不含临床建议`）**：`复诊准备`、`用药记录`、`症状日记`。
   - **正面识别 + 背面原理**：正面呈现 `1:1` 方形中文标注信息图、三项准备属性、关键一招与红色停手底线；支持**直接点击卡牌表面**或点击下方「翻面看解释」按钮（遵循 W3C Disclosure 规范，`aria-expanded` + 隐藏面 `inert`）查看每一步背后的医学原因；桌面端支持 `requestAnimationFrame` 弹簧阻尼 3D 倾角与柔光覆膜光泽。
2. **床旁伴读 · 大字跟做（`data-act="bedside"`）**
   - 针对照护现场双手被占或长辈老视场景，提供一步一屏的超大字无干扰向导，支持调用浏览器离线中文语音合成（`window.speechSynthesis`，`zh-CN` 慢速播报）朗读当前步骤，并与卡片详情页的步骤完成进度实时同步持久化。
3. **突发状况 · 红线速查（`data-act="redlines"`）**
   - 按情境（血压与心衰、血糖与胰岛素、跌倒与转移、呼吸与吸入、伤口·滴眼·认知）汇总各张临床指南卡中的「立即拨打急救电话」与「尽快联系医生」指征及「先别这样做」禁忌，每条均可跳回原卡并核对原始指南出处。
4. **疾病照护图谱枢纽与子卡扇形展开（86 个已核验枢纽）**
   - 基于 GBD 与 WHO 目录筛查整理 **86 个**已过筛常见健康问题枢纽（Tier 1 共 20 项、Tier 2 共 66 项），支持按 **5 个年龄段**（`0–5岁`、`6–17岁`、`18–44岁`、`45–59岁`、`60+岁`）与 **8 大身体系统**筛选。
   - 点击任意疾病枢纽，自动平滑滚入视野并原位展开 5 条核验标签、年龄与性别提示，配套的测量卡、给药操作卡、护理安全卡与复诊整理卡从身后扇形展开，支持一键批量加入「我的卡组」。
5. **本地优先病历夹、交互式多体征趋势图、一页复诊单与 JSON 备份**
   - **两步核对记录与交互式趋势读数条**：支持记录血压（高于 `180/120` 弹出红色警示）、指尖血糖（`≤ 3.9 mmol/L` 弹出低血糖红色警示）、晨起体重及上传病历图片/PDF（存本机 `IndexedDB`），切换「血压 / 血糖 / 体重」SVG 趋势折线图；悬停、点击或键盘聚焦任意数据点，读数状态条（`#chartReadout`）即时显示该次日期时间与数值。
   - **一页复诊单（`data-act="clinicsheet"`）**：汇总患者情况（演示数据显式标「虚构」）、想问医生的问题、在服药物清单、近期已确认三类体征均值/范围与症状记录，排版适配双栏 A4 打印。
   - **四步本地隐私脱敏整理**：粘贴病历文字后先在本地自动抹除姓名、身份证号、手机号、住址、编号与医疗机构，经用户逐行确认脱敏文本并阅读披露说明后才执行提取，提取结果默认标为「待核对」。
   - **防丢失 JSON 备份导出与导入恢复**：一键导出本机记录 JSON 并在导入时执行结构与数值范围校验，附带一键「撤销」恢复。

## 3. 医疗安全与工程合规铁规

- **51 份权威来源 100% 原文通读核对**：全库共收录 **51 份**权威临床指南与官方机构资料（国家卫健委、中国疾控中心、中华医学会、北京市卫健委、香港卫生署长者健康服务、WHO、英国 NHS、美国 NIH 下属 NIA/NHLBI/NEI、MedlinePlus、AHA 等），**51 / 51 条均已完成原文通读核对（`v:"ok"`）**，12 张临床卡全部达到 `◆◆◆ 来源全部核对` 等级。
- **零药名、零剂量建议**：给药操作卡只讲通用装置核对步骤与部位轮换，由 `review.py` 通过 `DOSE` 正则逐屏扫描拦截任何剂量单位字样。
- **红色唯一性（Red Exclusivity）**：全站浅色与深色双模式下，红色像素严格限定在 `.stop`、`.gen-stop`、`[data-stop]`、`.lvl-120`、`.stopstrip`、`.jump` 等停手就医区域内，分类色、待核对徽章与删除按钮一律不使用红色。
- **诚实疾病范围口径**：全站不宣称任何诸如「覆盖 99% 疾病」的百分比数字；全球疾病图谱标签统一使用「拨打当地急救电话 / 联系医护」，不把单一国家急救号码硬编码为全球默认；条件 ID `hypo`（甲状腺功能减退）与照护卡 `hypo`（识别低血糖）严格隔离。
- **无障碍与减弱动态**：锁定色彩令牌（`--bg:#F2F4F2`、`--card:#FFFFFF`、`--line:#E6E6E6`、`--ink:#0F0D0C`、`--brand:#255A41`、`--brand-2:#80C776`），支持浅色/深色/跟随系统与标准/大/特大三档字号，手机触控区 `≥ 44px`，开启系统 `prefers-reduced-motion: reduce` 或应用内「减弱动态」时自动关闭关键帧动画与 3D 倾斜。
